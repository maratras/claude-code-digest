# Claude Code Digest

Ежедневный автодайджест новостей про Claude Code.

Запускается каждый день в 09:00 МСК через GitHub Actions. Файлы дайджестов появляются в папке `digests/YYYY-MM-DD.md`.

## Источники

- **HackerNews** — упоминания "claude code" за последние 24 часа
- **Reddit** — r/ClaudeAI, r/MachineLearning, r/LocalLLaMA
- **GitHub** — релизы anthropics/claude-code и SDK
- **npm** — новые версии @anthropic-ai/claude-code и @anthropic-ai/sdk
- **YouTube** — новые видео канала Anthropic
- **Anthropic Changelog** — ссылка на страницу изменений

## Obsidian

Для синхронизации с Obsidian установи плагин [Obsidian Git](https://github.com/Vinzent03/obsidian-git) и клонируй этот репозиторий в папку внутри своего vault.
